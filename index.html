📊 Konfigurasi Database Google Sheets

Gunakan Google Spreadsheet sebagai database gratis & real-time! Data kunjungan dari pengunjung akan langsung tersimpan ke spreadsheet Anda.

Masukkan URL hasil Deploy Web App dari Google Apps Script.
📖 Cara Mudah Membuat Database Google Sheets (4 Langkah)
  1. Buka sheets.new untuk membuat Google Spreadsheet baru.
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode di sana, lalu tempel kode script yang ada di file google_apps_script.js di folder web ini.
  4. Klik tombol Terapkan (Deploy) > Penerapan baru (New deployment):
    • Pilih jenis: Aplikasi Web (Web app)
    • Jalankan sebagai: Saya (Me)
    • Siapa yang memiliki akses: Siapa saja (Anyone)
  5. Salin URL Aplikasi Web yang dihasilkan dan tempel pada kolom di atas!
